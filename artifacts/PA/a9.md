# A9: Product

The goal of this artifact is to demonstrate what was implemented in the product code, including US, libraries used, forms of access to the product and evaluation of the product's HTML and CSS.

The DreamTask App will allow any type of user, whether corporate related like startups, consultants, small companies, large businesses, and many others, to have control of all their workflow. The app allow users to have control of all their workflow by controlling and planning their activities and by helping to build the right line-up in order to assemble the perfect project.

```yaml

      summary: 'R101: Login Form'

        - 'M01: Authentication and Individual Profile'
      responses:
        '200':
          description: 'Ok. Show Log-in UI'
    post:
      operationId: R102
      summary: 'R102: Login Action'
      description: 'Processes the login form submission. Access: PUB'
      tags:
        - 'M01: Authentication and Individual Profile'
      requestBody:
        required: true
        content:
          application/x-www-form-urlencoded:
            schema:
              type: object
              properties:
                email:          # <!--- form field name
                  type: string
                password:    # <!--- form field name
                  type: string
              required:
                    - email
                    - password
      responses:
        '302':
          description: 'Redirect after processing the login credentials.'
          headers:
            Location:
              schema:
                type: string
              examples:
                302Success:
                  description: 'Successful authentication. Redirect to user profile.'
                  value: '/User/{id_user}'

                  description: 'Failed authentication. Redirect to login form.'

                  value: '/login'

    get:
```
